# Fruit Service Project (Simple Explanation)

## What is This Project?

This project is like a smart fruit shop system that helps you keep track of fruit prices, calculate costs, and make receipts. It works on a computer network, so you can use it from different computers at the same time.

## What Can It Do?

- **Add Fruits and Prices:** You can add new fruits and set their prices.
- **Update Prices:** If the price of a fruit changes, you can update it.
- **Delete Fruits:** Remove fruits that you no longer sell.
- **Calculate Cost:** Find out how much you need to pay for a certain amount of fruit.
- **Make Receipts:** Get a receipt for your purchase, just like in a real shop.

## How Does It Work?

- There are two main parts: a **server** (the brain) and a **client** (the user interface).
- The server keeps all the fruit information and does the calculations.
- The client is what you use to talk to the server, like a remote control.
- You can use the system from a computer program or through a simple website.

## Who Is It For?

- Shop owners who want to manage fruit prices easily.
- Cashiers who need to quickly calculate costs and print receipts.
- Anyone who wants to see how a simple shop system works on a computer network.

## How Do You Use It?

1. **Start the Server:** This is like turning on the main computer that does all the work.
2. **Open the Client:** This is what you use to add fruits, update prices, and make purchases.
3. **Follow the Menu:** The client shows a menu with options like "Add Fruit" or "Calculate Cost." Just pick what you want to do!

## Example

- You add "Apple" for $2.50 each.
- You want to buy 3 apples. The system tells you the total cost.
- You pay, and it gives you a receipt.

## Why Is This Cool?

- You can use it from different computers at the same time.
- It keeps everything organized and fast.
- It helps avoid mistakes with prices and receipts.

## Anything Else?

- The system comes with some fruits already added (like Apple, Banana, Orange, etc.).
- If you make a mistake, the system will let you know and help you fix it.

---

**In short:** This project is a simple, smart way to manage fruit sales on a computer, making life easier for shop owners and cashiers!
